Wer die App benutzt

Der Telegram Assistent ist ein privates Projekt. Er wird nur vom Besitzer für sein eigenes Google-Konto benutzt. Es gibt keine anderen Nutzer.

Welche Daten verwendet werden

  • Gmail: E-Mails lesen, durchsuchen und auf Wunsch in den Papierkorb verschieben.
  • Google Kalender: Termine lesen, erstellen, ändern und auf Einladungen antworten.

Wie die Daten verarbeitet werden

Die App läuft auf einem privaten Server des Besitzers. Für die Beantwortung von Anfragen werden die nötigen Inhalte (z.B. Absender, Betreff, Text einer Mail) an die Claude API von Anthropic gesendet. Die Antworten werden über Telegram an den Besitzer geschickt.

Die Zugangsdaten zu Google werden nur auf dem privaten Server gespeichert. Es werden keine Daten verkauft, für Werbung verwendet oder an andere weitergegeben.

Google API Services User Data Policy

Die Nutzung von Daten aus Google APIs hält sich an die Google API Services User Data Policy, einschliesslich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Zugriff widerrufen

Der Zugriff kann jederzeit unter myaccount.google.com/permissions entzogen werden.
